# Quazort_Up

Quazort_Up — приложение, которое значительно облегчает вашу спортивную жизнь. В нем есть Rock — наглядная схема человека с выделенными мышцами. Достаточно нажать
на любую мышцу, чтобы получить всю необходимую информацию о ней, а также список упражнений которые помогут качественно ее задействовать.

Кроме того, приложение содержит множество качественных советов от лучших спортсменов со всего мира.
